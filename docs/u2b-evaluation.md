No human approvals were collected. 42 ties use the same deterministic policy, measuring protocol/execution consistency, not model reasoning uplift.

PROVENANCE.json binds MIT source/case/question/label hashes; main's unseen set is private and absent.

Status and verified flags alone cannot establish correctness. Unknown usage/cost stays null; answerable handoffs stay failures.
