# Case study: a governed comparison that can decline to answer

A regional sales question can be wrong even when SQL executes. Joining lines,
refunds and fulfillment events together can multiply amounts; selecting the wrong
measure or cutoff can produce a plausible answer for the wrong question. Regional
grants and complete period coverage also determine whether an answer is possible.

The original local MVP independently demonstrated rejection of an authored fanout
query and a scoped verified result. U1 added a provider-shaped observation/tool
loop and full-semantic confirmation; main accepted its local-double evidence.
U2-A added a bounded fixed BigQuery snapshot importer; main accepted its local
contract, deadline correction and formatting overlay. That acceptance does not
prove external BigQuery access, IAM, billing state or live model quality.

U2-B adds a stronger deterministic baseline and a fresh authored corpus. A reviewer
can inspect `d07` for multiple lines/refunds, `d13` for a denied South request from
a North analyst, and `d17` for a source change after proposal. The intended outputs
are respectively a raw-fact-verified numeric comparison, an empty projection with
no SQL, and a typed failed non-answer before SQL. The native test also injects one
fanout candidate and expects shared bounded repair. These new workflows and demos
remain authored and unexecuted until a fresh main lease.

The tradeoff is deliberate: externally approved meaning and independent raw-fact
verification provide stronger evidence than a fluent answer, but require human
intervention and a bounded catalog. Four USD measures, two months, total/channel
grouping and trusted simulated identities remain the supported surface. Causal
claims, arbitrary formulas, authentication and live warehouse query planning are
outside that surface.

There is no U2-B task-success rate or measured improvement yet. The 42 tasks are
authored/exposed, and the offline protocol actor shares the baseline language
policy. Any future tie is a valid result; neither ties nor repeats measure a
model's value. Main must review the frozen local batch and independently hold
unseen cases before spending on a real model comparison. No production impact,
deployment, paid usage or external sandbox success is claimed.
